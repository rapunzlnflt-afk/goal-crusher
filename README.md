# Bootstraps

Savings-goal PWA by CleartrackApps. Pick a goal, get a grid of boxes, and crush them as you save.

- Grid styles: Even, Mixed, Count up
- Per-paycheck plan, weekly streak, printable grid
- Local-only storage with a backup file (bootstraps-backup.json)

Release checklist: bump APP_VERSION in index.html, version.json, and CACHE_VERSION in sw.js together.
